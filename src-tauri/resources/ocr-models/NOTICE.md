# OCR model attribution

This application bundles the PP-OCRv6 Small detection and recognition ONNX model artifacts and the associated PaddleOCR recognition dictionary for offline inference through RapidOCR.

- Upstream project: PaddleOCR / PaddlePaddle Authors
- Model family: PP-OCRv6 Small (detection + recognition)
- Model distribution source: RapidAI/RapidOCR model registry (ModelScope)
- Model license: Apache License 2.0
- Model copyright: Baidu and/or the applicable PaddleOCR rights holders
- Dictionary source: RapidOCR/PaddleOCR model assets; distributed with the upstream project terms

The model weights are not authored by ClipLingo. No endorsement by PaddlePaddle, Baidu, or RapidOCR is implied.

The model artifact SHA-256 values are recorded in `README.md` and are validated by RapidOCR's model registry during initialization.
